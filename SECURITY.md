# Security Policy

## Supported Versions

There's no backport or LTS policy (only the latest commit on `main` receives security fixes).

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability. Instead, report it privately by
emailing <theodorpeifer+vkube@gmail.com>.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce (e.g. a minimal `VClusterClaim` spec or API request that triggers it).
- Which parts are affected (portal, controller, Helm chart) and which commit/version.

## Response

This is a small project, so there's no formal SLA. Reports are taken seriously, so you can expect a response as soon as possible.

## Disclosure

Please allow a reasonable amount of time to investigate and address a reported issue before any
public disclosure.
