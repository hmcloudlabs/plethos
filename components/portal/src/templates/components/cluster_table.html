How to expose it

Deploy your app inside the cluster and create a Service for it named http in the default namespace, listening on port 80. Set --target-port to the port your app listens on: 

kubectl expose deployment <your-app> --name=http --namespace=default --port=80 --target-port=<app-port>

Your app is usually reachable at the URL above within a few seconds of creating the Service.
